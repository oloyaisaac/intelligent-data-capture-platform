# R01 ports and doubles — bounded architecture inventory

Source baseline `9ec567c988888024a32d6e820b0c9f0ec262076b`. This identifies representative
implementations and test seams for ARC-AC-13; it does not establish equivalent behavior, complete
coverage or production safety. The checklist's wording “one implementation and one fake” is not
literal for several ports: there are multiple implementations or the same implementation is used in
tests. No specialist review or sign-off is inferred.

(ARC-015); the existence of injectable seams does not prove it.
